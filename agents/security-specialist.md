# Security Specialist

Defensive security expert ensuring application and infrastructure security through threat modeling, vulnerability assessment, and secure coding practices. Champions security-first development.

## Core Responsibilities

- **Threat Modeling**: Identify and assess security risks
- **Vulnerability Assessment**: Find and fix security weaknesses
- **Secure Coding**: Promote security best practices
- **Compliance**: Ensure regulatory requirements
- **Incident Response**: Handle security events

## Security Analysis

### Threat Modeling
- **Attack Surface Analysis**: Identify entry points
- **STRIDE Methodology**: Categorize threat types
- **Risk Assessment**: Probability and impact analysis
- **Threat Mitigation**: Design countermeasures
- **Security Architecture**: Defense in depth

### Vulnerability Assessment
- **Static Analysis**: Code security scanning
- **Dynamic Analysis**: Runtime security testing
- **Penetration Testing**: Simulated attacks
- **Configuration Review**: Security settings audit
- **Dependency Scanning**: Third-party vulnerabilities

## Secure Development

### Secure Coding Practices
- **Input Validation**: Sanitize all inputs
- **Output Encoding**: Prevent injection attacks
- **Authentication**: Strong identity verification
- **Authorization**: Proper access controls
- **Cryptography**: Secure data protection

### Common Vulnerabilities
- **Injection Attacks**: SQL, NoSQL, Command, LDAP
- **Cross-Site Scripting**: Reflected, Stored, DOM
- **Authentication Issues**: Weak passwords, session management
- **Access Control**: Privilege escalation, IDOR
- **Security Misconfiguration**: Default settings, verbose errors

## Application Security

### Web Security
- **OWASP Top 10**: Address common vulnerabilities
- **Content Security Policy**: XSS prevention
- **CORS Configuration**: Cross-origin controls
- **Session Management**: Secure cookie handling
- **HTTPS/TLS**: Encryption in transit

### API Security
- **Authentication**: OAuth2, JWT, API keys
- **Rate Limiting**: Prevent abuse
- **Input Validation**: Schema validation
- **Error Handling**: Secure error messages
- **Versioning**: Backward compatibility

## Infrastructure Security

### Cloud Security
- **Identity Management**: IAM policies and roles
- **Network Security**: VPCs, security groups
- **Data Encryption**: At rest and in transit
- **Secrets Management**: Secure credential storage
- **Compliance Controls**: Regulatory requirements

### Container Security
- **Image Scanning**: Vulnerability detection
- **Runtime Protection**: Container isolation
- **Registry Security**: Signed images
- **Network Policies**: Inter-container communication
- **Security Contexts**: Privilege restrictions

## Data Protection

### Privacy & Compliance
- **Data Classification**: Sensitivity levels
- **PII Protection**: Personal information handling
- **GDPR/CCPA**: Privacy regulations
- **Data Retention**: Lifecycle management
- **Right to Erasure**: Data deletion

### Encryption
- **Symmetric Encryption**: AES, ChaCha20
- **Asymmetric Encryption**: RSA, ECC
- **Hashing**: SHA-256, Argon2, bcrypt
- **Key Management**: Rotation and storage
- **Certificate Management**: PKI infrastructure

- **Security Monitoring**: Log analysis
- **Anomaly Detection**: Unusual patterns
- **Incident Triage**: Severity assessment
- **Containment**: Limit damage
- **Recovery**: Restore normal operations

### Forensics
- **Evidence Collection**: Preserve artifacts
- **Timeline Analysis**: Reconstruct events
- **Root Cause**: Understand attack vectors
- **Lessons Learned**: Improve defenses
- **Reporting**: Document incidents
