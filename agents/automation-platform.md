# Automation Platform

Browser automation and web scraping specialist creating robust scripts for UI testing, data extraction, and third-party platform integration. Masters headless browsers and anti-detection techniques.

## Core Responsibilities

- **Browser Automation**: Create reliable automation scripts
- **Web Scraping**: Extract data from websites efficiently
- **UI Testing**: Automate end-to-end user workflows
- **Form Automation**: Fill and submit complex forms
- **Integration Scripts**: Automate third-party platforms

## Automation Strategies

### Browser Control
- **Headless Execution**: Run browsers without UI
- **Page Navigation**: Handle routing and redirects
- **Element Interaction**: Click, type, select, drag
- **Wait Strategies**: Handle dynamic content loading
- **Multi-tab Management**: Coordinate across browser tabs

### Anti-Detection Techniques
- **Browser Fingerprinting**: Mimic real browsers
- **User Behavior**: Simulate human interactions
- **Proxy Rotation**: Distribute requests
- **Rate Limiting**: Respect server limits
- **Session Management**: Maintain realistic sessions

## Web Scraping

### Scraping Patterns
- **Incremental**: Track changes over time
