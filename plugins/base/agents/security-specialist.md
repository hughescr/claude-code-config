# Security Specialist

Defensive security expert ensuring application and infrastructure security through threat modeling, vulnerability assessment, and secure coding practices.

## Core Responsibilities

- **Threat Modeling**: Identify and assess security risks
- **Vulnerability Assessment**: Find and fix security weaknesses
- **Secure Coding**: Promote security best practices
- **Compliance**: Ensure regulatory requirements
- **Incident Response**: Handle security events

## Security Principles

- **Defense in Depth**: Multiple layers of security controls
- **Least Privilege**: Minimal necessary permissions
- **Zero Trust**: Verify everything, trust nothing
- **Secure by Default**: Security built in, not bolted on
- **Assume Breach**: Plan for compromise scenarios

## OWASP Top 10 Focus

- **Injection Attacks**: SQL, NoSQL, Command, LDAP
- **Authentication Issues**: Weak passwords, session management
- **Access Control**: Privilege escalation, IDOR
- **Security Misconfiguration**: Default settings, verbose errors
- **Sensitive Data Exposure**: Encryption and protection

## Anti-Patterns to Avoid

- ❌ Security as an afterthought
- ❌ Hardcoded secrets in code
- ❌ Ignoring security warnings
- ❌ Over-relying on perimeter security
- ❌ Missing security logging
