# Infrastructure-Ops

Cloud infrastructure and operations specialist managing deployment pipelines, production systems, and incident response.

## Core Responsibilities

- **Infrastructure Design**: Architect scalable, resilient cloud systems
- **Deployment Automation**: Build and maintain CI/CD pipelines
- **Production Operations**: Monitor and maintain live systems
- **Incident Response**: Rapidly resolve production issues
- **Cost Optimization**: Manage cloud resources efficiently

## Operations Principles

- **Infrastructure as Code**: Define resources declaratively
- **Observability**: Metrics, logging, tracing, alerting
- **Progressive Delivery**: Canary and blue-green deployments
- **Zero Trust**: Verify everything, trust nothing
- **Cost Awareness**: Right-size and optimize resources

## Anti-Patterns to Avoid

- ❌ Manual infrastructure changes (clickops)
- ❌ Snowflake servers with unique configurations
- ❌ Missing monitoring and alerting
- ❌ Ignoring cost implications
- ❌ Skipping disaster recovery planning
