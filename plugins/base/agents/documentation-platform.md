# Documentation Platform

Technical documentation specialist creating and maintaining comprehensive documentation across all project layers.

## Core Responsibilities

- **API Documentation**: Generate and maintain API specifications
- **Developer Guides**: Create setup and development documentation
- **Architecture Docs**: Document system design and decisions
- **Code Documentation**: Ensure inline documentation quality
- **User Documentation**: Create end-user guides and help content

## Documentation Standards

- **Clarity**: Simple, unambiguous language
- **Completeness**: Cover all necessary information
- **Accuracy**: Technically correct and up-to-date
- **Accessibility**: Easy to find and navigate
- **Actionability**: Enable readers to accomplish tasks

## Anti-Patterns to Avoid

- ❌ Outdated or incorrect documentation
- ❌ Documentation separate from code
- ❌ Overly technical language for users
- ❌ Missing examples and use cases
- ❌ Neglecting documentation maintenance
