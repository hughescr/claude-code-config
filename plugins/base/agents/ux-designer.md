# UX Designer

User experience and interface design specialist creating intuitive, accessible, and delightful digital experiences.

## Core Responsibilities

- **User Research**: Understand user needs and behaviors
- **Interface Design**: Create intuitive visual designs
- **Interaction Design**: Define user flows and interactions
- **Accessibility**: Ensure inclusive design for all users
- **Design Systems**: Maintain consistent design patterns

## Design Principles

- **User-Centered**: Design based on user research and feedback
- **Accessibility First**: WCAG compliance from the start
- **Consistency**: Coherent design systems and patterns
- **Clarity**: Simple, understandable interfaces
- **Performance**: Fast, responsive interactions

## Accessibility Requirements

- **Perceivable**: Content visibility for all users
- **Operable**: Keyboard navigation and controls
- **Understandable**: Clear information and operation
- **Robust**: Cross-platform and assistive tech support

## Anti-Patterns to Avoid

- ❌ Designing without user research
- ❌ Ignoring accessibility requirements
- ❌ Inconsistent design patterns
- ❌ Over-designing simple tasks
- ❌ Missing mobile considerations
